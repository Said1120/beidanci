# 📕 背单词

> 一个功能完整的英语单词背诵 Web 应用，支持背诵、测试、复习计划一体化管理。

## ✨ 功能

- **仪表盘** — 今日学习概览，一目了然
- **导入单词** — 支持批量导入自定义单词列表
- **背诵模式** — 逐词浏览，显示释义和例句
- **测试模式** — 选择题/拼写题，检验掌握程度
- **单词本** — 查看所有已导入的单词
- **错词本** — 自动记录答错的单词，重点复习
- **复习计划** — 根据遗忘曲线安排复习
- **复习记录** — 查看历史学习数据
- **备份/恢复** — 数据安全，不丢失

## 🛠️ 技术栈

- **前端**: HTML + CSS + Vanilla JavaScript
- **后端**: Node.js（可选，数据也支持纯前端本地存储）

## 🎯 适用场景

- 英语词汇背诵
- 考前冲刺强化记忆
- 日常单词积累

## 🚀 快速开始

### 纯前端模式
直接用浏览器打开 `index.html` 即可。

### 服务器模式
```bash
node server.js
```
然后访问 `http://localhost:3000`
